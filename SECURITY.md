# Security

Aioros.Pictor is in **preview**. It is not yet recommended for production, and only the latest preview receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub's [private vulnerability reporting](https://github.com/singularengine/aioros-pictor/security/advisories/new), with the steps to reproduce it and the version affected.

You will get an answer as soon as possible. Fixes are published in a new preview, and the advisory is made public once a fix is available.
