# Roadmap

What Aioros.Pictor covers today and what comes next. It is in public preview, so its APIs can still change.

## What exists today

- [x] Every chart family of Recharts 2.15.4, compared with Recharts' own render
- [x] Interaction on the web and the desktop: hover, touch, keyboard, legend toggles, brush and live charts
- [x] Enter and update animations on both targets
- [x] Themes, styles, resources and data binding as a native XAML control
- [x] Custom content as `DataTemplate`s
- [x] Links on items and per-item styles from data
- [x] Preview packages on NuGet

The full list, row by row, is in [Coverage](coverage.md).

## What comes next

- A project template on NuGet, so a new app can start with a dashboard.
- A chart with a fixed height that keeps exactly that height between its `ResponsiveWidths`, which would need a script that lays the chart out at the client's width.
- Whatever real apps ask for.
