# Custom content

Recharts' custom content (a `shape`, `dot`, `tick`, `label` or `content` element or function, which receives the item's
props and returns SVG) as XAML templates: a slot's `DataTemplate` whose data context is the item's props (a
`BarShapeContext`, a `DotContext`...), made of Avalonia's shapes (`Path`, `Rectangle`, `Ellipse`, `Line`, `Polygon`,
`Polyline`, `TextBlock`, panels and `Viewbox`) and Pictor's template shapes (`SvgText`, `Sector`, `Dot`, `Rectangle`,
`Symbols`, `Layer`). The template is compiled once to SVG with holes (Avalonia lays it out with marked values, and every
number is read back as an affine function of the context's numbers, every color and text as a member or a literal,
every visibility as a condition); the web writes it per item without Avalonia and the desktop draws the same nodes,
while a template that cannot be compiled is refused with its reason (the web renders the page with Avalonia, the
desktop lays the template out per item). Reference examples in `tools/recharts/catalog/custom.mjs`, ported with the
templates of `tests/Aioros.Pictor.Tests/Custom/CustomTemplates.axaml` and the Gallery's `/custom` page.
