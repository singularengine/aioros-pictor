# Gaps closed after the coverage audit

Recharts 2.15.4 props and behaviors whose code existed without a criterion, or that were missing, checked on reference
examples rendered by Recharts itself (`tools/recharts/catalog/gaps.mjs`, `tools/recharts/out/<name>.client.html`)
with the comparison of [charts.md](charts.md) (`MarkupComparison`) and, for tooltips, the hover comparison of
[tooltips-legends.md](tooltips-legends.md) (`HoverComparison`) after the same pointer events in Chromium.
