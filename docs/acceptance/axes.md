# Axes, labels, scales, curves and stacking

Recharts 2.15.4's axes, labels, scales, curves and stack offsets, checked on reference examples rendered by Recharts
itself (`tools/recharts/catalog/axes.mjs`, `tools/recharts/out/<name>.client.html`) with the comparison of
[charts.md](charts.md) (`MarkupComparison`), which also compares a text's rotation and its own font size.
