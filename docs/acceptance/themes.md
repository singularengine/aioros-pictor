# Themes and styles

A chart is themed the way XAML themes controls (decision "Themes as resource dictionaries"): `PictorTheme`, included
once in the application's styles, holds a light and a dark dictionary with a key for every default the charts draw
(`PictorKeys`); a key redefined in the application's, a window's, a page's or a chart's resources wins there, and a
property set on an element wins over every key. The chart resolves its theme from its resources once per change of
theme variant or resource, and carries it in its spec (`ChartSpec.Theme`, `ChartTheme`), so the web writer and the
desktop painter draw the same colors. Chart elements are styled elements in the chart's logical tree, so Avalonia's
styles, control themes, resources and the data context reach them. The light theme is Recharts' own defaults; the
dark theme is Pictor's (values and contrast in `ChartTheme.Dark`).
