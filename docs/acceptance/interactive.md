# Interactive charts

Recharts' clicks as Aioros commands, a nest treemap's zoom, charts sharing their active category (`syncId`) and charts
updated live. On the web a click target is an HTML button over the item, the framework's command button with its
parameter (a text, as a literal `CommandParameter` is), posted without script and answered with the chart's region;
on the desktop the pointer runs the same command with the same parameter. Recharts' hover events (`onMouseEnter`,
`onMouseLeave`, `onMouseMove`) are not offered as commands: on the web each would be a request per pointer movement,
and what Recharts uses them for (the active shape, the tooltip, the cursor) Pictor draws without a request.
